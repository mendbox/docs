# Add-on manuals

User manuals for three Blender add-ons by Mendbox Studio. Support: support@mendboxstudio.com

| Add-on | Version | What it does | Manual |
|---|---|---|---|
| QuadFix | 1.4.5 | Fill holes with quads, n-gons to quads, Boolean and import cleanup, Bridge to Quads, Union to Quads | [Open the manual](quadfix/index.md) |
| Image Per Instance | 0.2.0 | A different image on every object or Geometry Nodes instance with one material | [Open the manual](image-per-instance/index.md) |
| BedSplit | 0.1.3 | Split a model into parts that fit your 3D printer bed, with dowels | [Open the manual](bedsplit/index.md) |

All three need Blender 4.2 or newer. Tested on Blender 4.2.23, 4.5.14 and 5.2.2 on macOS. QuadFix and Image Per Instance also work on Windows (tested on Windows 11, x86-64) and Linux.
